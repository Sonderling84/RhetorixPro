Wo die Realität vom Plan abweicht. Nach Kategorie, mit Fix.

Beim Nachbau echter Gebäude tauchen immer wieder dieselben Problemklassen auf. Jede Korrektur landet hier als Regel: lesbar für dich, maschinenlesbar für andere Planer, Skills und KI-Systeme. Wer den Feed liest, muss den Fehler nicht noch einmal finden.

Für andere Systeme

Alle Einträge liegen als JSON-Feed bereit. Eine App, ein Skill oder ein Planer holt den Feed, filtert nach Kategorie und Zielsystem und wendet Regeln mit fix_automatisch: true direkt an.

feed.json
So übernimmt ein System die Regeln
  1. Feed laden und aktualisiert mit dem letzten Stand vergleichen.
  2. Einträge nach ziel_systeme filtern, zum Beispiel nur spec-parser.
  3. Regeln mit fix_automatisch: true und Status bestaetigt anwenden.
  4. Vorläufige Regeln nur zur Prüfung markieren, nicht automatisch ausführen.
const feed = await (await fetch(FEED_URL)).json();
const fixes = feed.eintraege.filter(e =>
  e.ziel_systeme.includes("spec-parser") &&
  e.fix_automatisch && e.status === "bestaetigt");
Mitmachen

Jeder Beta-Bau kann neue Einträge liefern. Mit dem Häkchen im Kundenbereich erlaubst du die anonymisierte Veröffentlichung. Dein Plan selbst bleibt immer privat.
