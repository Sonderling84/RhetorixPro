# Medien für die Startseite

Dateien hier ablegen, die Seite bindet sie automatisch ein. Fehlt eine Datei, bleibt das Feld unsichtbar.

| Datei | Wofür | Vorgabe |
|---|---|---|
| `hero.jpg` | Vorher/Nachher im Hero (Plan links, 3D rechts) | 1600×1000 px, JPG, unter 300 KB |
| `01.jpg` … `05.jpg` | Galerie "Einblicke" | 1200×900 px (4:3), JPG, unter 200 KB |
| `clip-01.mp4`, `clip-02.mp4` | Videos in der Galerie | H.264, 1080p, 16:9, unter 5 MB, ohne Ton oder mit Ton (Start stumm) |
| `clip-01.jpg`, `clip-02.jpg` | Vorschaubilder der Videos | 1280×720 px, JPG |
| `og-image.jpg` | Vorschaubild beim Teilen (WhatsApp, LinkedIn) | 1200×630 px, JPG |
| `vergleich-1-vorher.jpg` + `vergleich-1-nachher.jpg` | Schieberegler "Vom Plan zum Rohbau" | beide 1600×900 px (16:9), gleicher Ausschnitt |
| `vergleich-2-vorher.jpg` + `vergleich-2-nachher.jpg` | Schieberegler "Agentur-Render vs. Matrix Architekt" | beide 1600×900 px, gleicher Blickwinkel |
| `vergleich-3-vorher.jpg` + `vergleich-3-nachher.jpg` | Schieberegler "Foto vs. Modell" (Bestand) | beide 1600×900 px |
| `stil-1-neon.jpg` … `stil-6-historisch.jpg` | Die sechs Darstellungsstile | 1200×900 px (4:3); liegen schon drin, gern durch Originale ersetzen |

## Was gute Vergleichsbilder ausmacht

- **Gleicher Ausschnitt, gleicher Blickwinkel** für Vorher und Nachher. Der Schieberegler lebt davon, dass die Kanten übereinander liegen.
- Bei "Plan → Modell": den Grundriss so drehen, dass die Hauptfassade unten liegt, und das Modell in Draufsicht oder leichter Isometrie zeigen.
- Keine fremden Renderings verwenden (Agentur-Bilder sind urheberrechtlich geschützt). Für Paar 2 ein eigenes Rendering in fotorealistischem Stil gegen den Blueprint-Stil stellen.
- Videos: 10 bis 30 Sekunden, ohne Intro, Start direkt in der Aktion (Plan liegt, Wände wachsen hoch). Stumm funktioniert, Ton ist Bonus. Unter 5 MB, H.264, 1080p.

Bilder vor dem Upload verkleinern (z. B. mit Squoosh oder ImageOptim). Große Dateien bremsen die Seite und kosten Conversion.
